# Adaa Admin Portal — Design System

Catalogue des composants du socle UX/UI React (voir `README.md` à la racine
du projet pour l'architecture complète).

Utiliser le sélecteur **Thème** dans la barre d'outils pour basculer entre
mode clair et sombre et vérifier que chaque composant reste lisible dans
les deux.

## Organisation

- **UI/** — composants génériques (Button, Card, Badge, Select, Modal...)
- **Tables/** — DataTable générique (tri, recherche, pagination, export CSV)

Chaque composant nouvellement ajouté au socle doit avoir son fichier
`*.stories.tsx` à côté de son implémentation.
